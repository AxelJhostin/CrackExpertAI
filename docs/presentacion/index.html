Por qué existe

La fisura está ahí. Interpretarla es otra cosa.

Inspeccionar a mano es lento y subjetivo. Una CNN puede marcar la grieta. No puede decir si es retracción o cortante, ni qué exige el código en Manabí.

La idea

Dos capas que no se pisan

Cambiar una regla del código no reentrena la red. Cambiar el modelo no mueve wmax. Esa separación es el sistema.

Cómo corre una foto

De la cámara al dictamen

1. Foto

JPG o PNG, 224×224. Una visita guarda varias tomas del mismo lugar.

2. CNN

P(fisura). Si es menor a 0,50, se acaba: no hay grieta visual.

3. OpenCV

Vertical, horizontal, inclinada o malla. El inspector puede corregir.

4. Campo

Elemento, ambiente y 9 cartas. «No lo sé» no inventa hechos.

5. Experto

Severidad, mecanismo, plan y certeza MYCIN. Alerta, no peritaje.

La red que se despliega

CNN hecha a mano, 1,3 MB

224×224 RGB → [0, 1]
Conv 32 + BN + ReLU + Pool + Drop 0,25
Conv 64 + BN + ReLU + Pool + Drop 0,25
Conv 128 + BN + ReLU + Pool + Drop 0,25
GAP → Dense 128 → Drop 0,50 → sigmoid P(fisura)
def build_cnn_custom():
    x = Rescaling(1/255)(inputs)
    for f in (32, 64, 128):
        x = Conv2D(f, 3, padding="same")(x)
        x = BatchNormalization()(x)
        x = Activation("relu")(x)
        x = MaxPooling2D(2)(x)
        x = Dropout(0.25)(x)
    x = Dense(128, "relu")(GAP(x))
    return Dense(1, "sigmoid")(x)

Entrenamiento

La CNN se estabiliza cuando baja el learning rate

Cómo se lee: cuando las curvas de pérdida bajan y validación acompaña a entrenamiento, la red está aprendiendo. Aquí la fase 2 suaviza la convergencia; EarlyStopping conserva el mejor punto. El test no participó.

Inferencia

Reglas hacia adelante y certeza MYCIN

R0 — P < 0,50 → no hay fisura visual.

R1 — P ≥ 0,50 → hay fisura, arranca en leve.

R6b — sin milímetros → no se inventa el ancho.

R-P1 — diagonal en apoyos → cortante crítica.

R-P7 — paralela al acero → corrosión.

De la red al experto CFP = 2P − 1

P = 0,50 no aporta. P = 0,92 da CF 0,84.

CFcomb = CFa + CFb(1 − CFa)

Gana la severidad más grave. «No lo sé» no dispara la regla.
